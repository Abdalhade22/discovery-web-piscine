# Project 00 - Linux + Git + GitHub

## Project Overview

This project is about learning Linux terminal, file commands, Git and GitHub.

I learned how to create folders and files, use Git, make commits and push my work to GitHub.

## What I Learned

In this project I learned:

- How to use the Linux terminal
- How to create and move between folders
- How to create, copy, rename and delete files
- How to use Git
- How to create commits
- How to connect Git with GitHub

## Linux and Terminal

I used commands like:

- pwd
- ls
- cd
- mkdir
- touch
- cp
- mv
- rm
- cat

These commands helped me work with files and folders using the terminal.

## Git and GitHub

Git helps me save the changes I make in my project.

GitHub is used to store the project online.

I used git add, git commit and git push to save and upload my work.

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of my changes.

I can see what I changed and keep different commits for my work.

If something goes wrong, I can look at older commits.

Git also makes it easier to work with other people because everyone can keep track of changes.
